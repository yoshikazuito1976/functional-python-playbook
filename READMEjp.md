# Pythonで学ぶ関数型思考（Functional Thinking with Python）

このリポジトリは、**Pythonを使って関数型プログラミングの考え方を学ぶための個人的な学習記録**です。

ここで扱うのは、  
いわゆる「純粋関数型言語」を習得することではありません。

Pythonという馴染みのある言語を通して、

- 予測しやすいコード
- テストしやすいコード
- 他者に説明できるコード

を書くための **関数型的な思考習慣** を身につけることを目的としています。

---

## なぜ Python で関数型思考なのか

Pythonは関数型言語ではありません。  
しかし、以下のような関数型の考え方を実践するには十分な柔軟性を持っています。

- 「どう書くか」より「何をしたいか」を先に考える
- 状態変更や副作用を減らす
- 入力と出力の関係を明確にする
- 処理の流れをデータ変換として捉える

これらは、

- 教育
- 設計
- チーム開発
- 生成AIを活用した開発

といった文脈で、特に重要になりつつある考え方です。

---

## このリポジトリが目指すもの／目指さないもの

### このリポジトリが目指すもの
- 学習途中の思考や試行錯誤をそのまま残すこと
- 「なぜそう考えたか」を説明できる形にすること
- コードを書く前の設計や分解の質を高めること
- 小さく、読みやすく、検証しやすいコードを書くこと

### このリポジトリが目指さないもの
- 関数型プログラミングの網羅的解説
- Pythonの最適化テクニック集
- 高度な抽象概念（モナド、圏論など）の解説

内容が未完成だったり、素朴に見えたりする部分があるかもしれません。  
それは **「学びの途中であること」を前提にしているため**です。

## 扱う主なテーマ

このリポジトリでは、主に以下のようなテーマを扱います。

- 純粋関数（同じ入力には同じ出力）
- 不変データと状態の扱い方
- map / filter などによるデータ変換
- 処理をパイプラインとして捉える考え方
- 例外ではなく「値」としてのエラー表現
- 副作用（I/O）を境界に閉じ込める設計
- テストしやすいコードの書き方

特別なライブラリは極力使わず、  
**素のPythonで考え方を身につける**ことを重視します。

---

## 想定している読者

このリポジトリは、主に次のような人を想定しています。

- Pythonの基本文法（if / for / def）は分かる
- コードは書けるが、説明や設計が苦手だと感じている
- 状態が増えるとコードが読めなくなる
- AIにコードを書かせたとき、正しさを判断しづらい
- プログラミングを「思考の道具」として使いたい

また、このリポジトリは **将来の自分自身** に向けて書かれています。

## 使い方（おすすめ）

特定の順番はありませんが、以下の流れがおすすめです。

1. `docs/` 配下のドキュメントを読む  
2. `exercises/` の課題を自分で考えてみる  
3. （あれば）`solutions/` を確認する  
4. 「なぜこちらの方が説明しやすいか」を考える  

正解を覚えるより、  
**考え方の違いを言葉にすること**を大切にしています。

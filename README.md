# functional-python-playbook
# Functional Python Playbook  
（関数型で Python を知る）

## 概要

このリポジトリは **Python を「関数型プログラミングの視点」から理解する** ための学習用プレイブックです。

- Python はマルチパラダイム言語であり  
  **命令型・オブジェクト指向・関数型**の要素を併せ持っています。
- 本リポジトリでは、その中でも  
  **「状態を減らす」「処理を分解する」「考え方を明示する」**  
  という関数型的な思考に焦点を当てます。

アルゴリズム競技や純粋関数型言語を目指すものではありません。  
**読みやすく・考えやすく・壊れにくい Python** を目指します。

---

## 対象読者

- Python 基礎文法を一通り学んだ人
- 「書けるけど、設計が不安」な人
- 命令型コードが複雑になりがちな人
- 教育・レビュー・設計視点を鍛えたい人

※ 完全初学者向けではありません。

---

## このリポジトリで扱うこと

- 副作用を減らす考え方
- データと処理の分離
- 小さな関数への分解
- map / filter / reduce の実践的利用
- イミュータブルな発想
- テストしやすいコード設計
- 「なぜそう書くのか」の言語化

---

## 扱わないこと

- 純粋関数型言語としての Python 解釈
- 数学的定義や圏論
- パフォーマンス最優先の最適化
- フレームワーク依存の実装

## 学び方のおすすめ

1. **コードを読む**
2. 「何が入力で、何が出力か」を確認する
3. 副作用がどこにあるかを探す
4. 関数をさらに小さくできないか考える
5. 命令型と比較して違いを言語化する
